# LLM Project

Snowman is a localhost based game that is similar to hangman. This is the improved version of the original Python project, but here I experiemtn with LLMs to build this.

## Key Features and Extensions

- **Three difficulty levels:** Easy, medium, and hard use different word lists and numbers of guesses.
- **Letter and word guesses:** Players select individual letters or try to solve the entire word.
- **Hints:** Hints reveals the first two letters at the cost of one guess.
- **Score system:** Correct and incorrect guesses change the players score.
- **Bonus round:** Winning the main round unlocks another word with no hints
- **Animated snowman:** The CSS snowman shrinks and melts, and forms a larger puddle as guesses run out.
- **Python web server:** A server connects the browser interface to the Python game logic.
- **Terminal mode:** You can still run the orignla using snowman.py.
